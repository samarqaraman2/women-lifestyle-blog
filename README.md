# Women Lifestyle Blog

Women Lifestyle Blog is a modern Django-based web application designed for publishing lifestyle articles and managing dynamic blog content.

## Features

- Article publishing system
- Image uploads
- Responsive user interface
- Category organization
- Django admin panel
- Media management
- Clean and modern design

## Technologies Used

- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite

## Installation

```bash
git clone https://github.com/samarqaraman2/women-lifestyle-blog.git
cd women-lifestyle-blog
pip install -r requirements.txt
python manage.py runserver
```
